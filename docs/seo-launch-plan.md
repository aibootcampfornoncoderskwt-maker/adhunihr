# SEO, GEO/AEO and backlink plan

Domain: https://adhunihrsolutions.com. Indexing stays off until `PUBLIC_LAUNCH_READY=true`.

## Built into the site
- Real static Arabic pages at `/ar/...` (generated by `scripts/generate-arabic.mjs` during `npm run build`), with hreflang (en, ar, x-default), Arabic canonicals and a bilingual sitemap.
- Unique titles and descriptions, one H1 per page, canonical, Open Graph, JSON-LD (Organization, WebSite, page type, BreadcrumbList, Service, FAQPage).
- `robots.txt`: blocks everything in review mode; at launch allows search and AI crawlers, excludes `/api/`, lists the sitemap.
- `/llms.txt`: plain-text map of the site for AI assistants.
- `npm run check:seo` audits the build (`-- --launch` for the launch build).

## Launch checklist (owner)
1. Vercel env: `SITE_URL=https://adhunihrsolutions.com`, `PUBLIC_LAUNCH_READY=true`, `PUBLIC_CONTACT_ENABLED=true`, Resend and Turnstile keys.
2. Redeploy, then run `npm run build` locally with those values and `npm run check:seo -- --launch`.
3. Google Search Console: add the domain property, verify by DNS, submit `https://adhunihrsolutions.com/sitemap-index.xml`. Do the same in Bing Webmaster Tools.
4. Add analytics (GA4 or Plausible); the site already emits events through `src/scripts/analytics.ts`.
5. Have a native Arabic speaker review `src/data/seo-arabic.json` and the Arabic pages.

## GEO / AEO (answer engines)
- Keep each page opening with a direct, factual answer (what we recruit, where, how to start).
- Add guides only with real, checkable content: for example "How licensing works for nurses in each GCC country" (cite official regulators), "What to put in a hiring brief".
- Never invent statistics, placements or reviews.

## Programmatic pages (next)
Healthcare and oil and gas by country (12 pages), then role pages. Each page needs genuinely different content (regulator, licensing path, typical roles, process). Keep them `noindex` until the copy is real and reviewed.

## Backlinks (off-site, no bought links)
- Google Business Profile and LinkedIn company page (needs real business details from the owner).
- GCC and India recruitment and healthcare directories, chambers of commerce, trade associations.
- Partnerships: hospitals, training institutes and nursing colleges linking to the candidate page.
- Publish useful guides, then share them in LinkedIn groups and industry forums.

## Leads
- Add a booking link or WhatsApp number once real (env vars already supported).
- Offer a downloadable hiring checklist in exchange for an email.
- Run Google Ads on "nurse recruitment Kuwait"-type queries while organic ranking builds. No one can promise a #1 position; rankings take months.
